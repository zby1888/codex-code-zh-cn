# Codex 0.169.0 原生中文补丁

此目录存放针对 `openai/codex` 的 `rust-v0.169.0` 源码补丁。GitHub Actions 会在 Termux 官方构建环境中将这里的 `*.patch` 文件应用到 `packages/codex`，然后编译 Android ARM64 版本。

## 提交规则

- 译文必须人工撰写或人工逐条审校；未经审校的机器翻译不得直接合入。
- 每个补丁尽量只改一个清晰的 TUI 模块，便于回滚和审查。
- 不改变命令执行逻辑、权限逻辑、协议、配置格式或模型请求内容。
- 保留 Rust 格式占位符（例如 `{name}`、`{count}`）、转义符和换行语义。
- 不翻译命令名、快捷键、路径、环境变量、模型/provider 标识、JSON/RPC 字段和代码示例。
- 对动态字符串添加测试，避免占位符丢失、格式错误或中文终端宽度异常。
- 每个补丁说明对应的上游文件和人工校对范围。

## 优先模块

1. 启动欢迎页和帮助提示
2. 斜杠命令候选及描述
3. 权限与命令执行确认
4. 模型、推理强度和配置弹窗
5. 设置、主题、快捷键和状态栏
6. Agent、Skills、MCP、插件和会话管理
7. 错误、警告、诊断和用量提示

当前先完成未修改上游源码的 Android ARM64 基线构建；确认构建链路后再加入第一个人工翻译补丁。
